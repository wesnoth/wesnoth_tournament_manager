# Map packs

Map packs are reusable administrative collections of canonical game maps. Administrators and moderators can create, update, deactivate, and delete packs from the Maps, Factions & Map Packs page. Map records remain independently managed by administrators, and one map may belong to multiple packs.

Tournament organizers can read active packs during setup. Applying a pack replaces the current map checkbox selection with the active maps from that pack that are eligible for the tournament mode. The organizer can then adjust individual maps normally.

Pack selection is intentionally transient. Tournament requests and database records contain only the resulting map IDs; they never store a map pack identifier. Consequently, editing or deleting a pack cannot change an existing tournament.

Inactive packs are hidden from tournament setup. Inactive maps remain visible to pack managers for maintenance but are excluded when a pack is applied. Ranked tournament setup exposes only ranked maps from each available pack.
