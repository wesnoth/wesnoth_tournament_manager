# Medieval theme assets

These files are self-hosted copies of assets from the wesnoth.org website
theme ([wesmere](https://github.com/wesnoth/wesmere), GNU GPL v2 or later).

| Files | Origin | License |
| --- | --- | --- |
| `fonts/montaga-latin.woff2` | Montaga, by Alejandra Rodriguez | SIL Open Font License 1.1 |
| `fonts/opensans-*.woff2` | Open Sans, by Steve Matteson | SIL Open Font License 1.1 |
| `img/front-background.jpg`, `img/logo-large*.png` | The Battle for Wesnoth project artwork, as used by wesnoth.org | GNU GPL v2 or later |

Only the Latin, Latin Extended, Cyrillic and Cyrillic Extended font subsets
are included, which cover the interface locales except Chinese (rendered with
system fonts).
